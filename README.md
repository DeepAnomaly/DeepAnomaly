# DeepAnomaly 🩸

**La IA sin límites, sin censura y 100% local.**

DeepAnomaly es un proyecto OpenSource y sin fines de lucro (donaciones opcionales). Nace como una alternativa real a las IAs comerciales que te cobran por tokens, te limitan el uso ("vuelve en 1 hora") o te bloquean por preguntas inofensivas.

## 🚀 Características
*   **100% Local:** Corre en tu teléfono (Android) o PC (Windows). Tus datos y chats nunca salen de tu dispositivo.
*   **Sin Censura:** Respuestas directas, sin sermones moralistas. Tú decides qué preguntar.
*   **Motor en Rust 🦀:** Máximo rendimiento, cero lag y uso eficiente de la memoria RAM.
*   **MCP Integrado (Próximamente):** Conexión directa con Roblox Studio y Blender para generar código en tiempo real.
*   **Sin límites de tokens:** Tu hardware es el único límite. No hay servidores centrales ni cobros ocultos.
*   **Humanizador de Código (Próximamente):** La IA reescribirá el código generado para que se vea 100% humano, sin marcas de agua.

## 🛠️ Stack Tecnológico
*   **Core:** Rust (Axum, Tokio)
*   **App:** Android / Windows
*   **Modelos:** LLMs OpenSource (ejecución local)
*   **Logins:** GitHub, Google, Discord, Roblox (credenciales 100% gratis).
